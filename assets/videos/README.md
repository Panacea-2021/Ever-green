# Home hero video

Drop a short, muted, seamlessly-looping clip here named:

    home_hero.mp4

Recommended: 6-10s, H.264/MP4, ~720p, portrait or landscape (it is
center-cropped with BoxFit.cover). Keep the file small (a few MB) so app
startup stays fast.

If this file is missing, the Home screen falls back automatically to
`assets/images/home_banner.png`, then `login_bg.png`, then a gradient
placeholder - so the app always builds and runs without a video present.
